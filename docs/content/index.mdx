Lawbook checks code standards with repeatable rules and LLM decisions. It
ships as an npm package and needs Node.js 22.12 or newer.

The tool is at an early stage and has no commands yet. This site will grow
with it.

## Build from source

With Node.js 22.12 or newer and pnpm, from a clone of the repository:

```sh
pnpm install
pnpm run build
npm install --global .
```

Then check the install:

```sh
lawbook --version
```
