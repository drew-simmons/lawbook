Lawbook checks a directory against the rules in its `lawbook.yaml`. The rules
are repeatable: the same files always give the same result, and a failing
rule names the file and line that broke it. It ships as an npm package and
needs Node.js 22.12 or newer.

```sh
npm install --global lawbook
lawbook init
lawbook check
```

- [Getting started](/getting-started) walks through the first run.
- [Configuration](/configuration) describes the rule kinds and the config file.
- [Commands](/commands) lists every command and flag.
- [Exit codes](/exit-codes) says what `0`, `1`, and `2` mean.

LLM-judged rules, where a standard written in prose is applied by a model,
are the next step for the project and are not available yet.

## Build from source

With Node.js 22.12 or newer and pnpm, from a clone of the repository:

```sh
pnpm install
pnpm run build
npm install --global .
```

Then check the install:

```sh
lawbook --version
```
