Lawbook checks code standards with repeatable rules and LLM decisions. It
ships as one binary with no runtime dependencies.

The tool is at an early stage and has no commands yet. This site will grow
with it.

## Build from source

With Rust 1.88 or newer, from a clone of the repository:

```sh
cargo install --path . --locked
```

Then check the install:

```sh
lawbook --version
```
